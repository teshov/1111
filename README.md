# Приглашение для Кристины ❤️

Мини-сайт-приглашение от Артура.

## Фотографии

Сейчас сайт использует первые 3 фотографии из присланных ссылок Imgur.

Чтобы заменить их, открой `style.css` и измени URL в:

- `.photo-1` — первый экран
- `.photo-2` — приглашение
- `.photo-3` — финальный экран

Оставшиеся ссылки можно подключить позже.

## Публикация

Сайт состоит только из HTML, CSS и JavaScript и подходит для GitHub Pages.
